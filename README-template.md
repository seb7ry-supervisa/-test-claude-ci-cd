## 📖 Uso general
1. Ingresa a [http://localhost:3000](http://localhost:3000) en el navegador.
2. Inicia sesión con tus credenciales.
3. Accede al módulo **"Control Vehicular"**.
4. Visualiza los accesos en tiempo real, realiza búsquedas y exporta registros.

## 🛠 Tecnologías utilizadas

- **Node.js** `vX.X.X`  → Backend API
- **Express** `vX.X.X`  → Framework del servidor
- **PostgreSQL** `vX.X.X`  → Base de datos relacional
- **Sequelize** `vX.X.X`  → ORM para Node
- **React** `vX.X.X`  → Portal Web
- **Docker** `vX.X.X` → Contenedores para despliegue
- **OpenALPR** `vX.X.X` → Reconocimiento de placas (en versiones avanzadas)
- **WebSocket** `vX.X.X` → Comunicación en tiempo real
